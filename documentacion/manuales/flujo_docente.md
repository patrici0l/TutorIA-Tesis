# Recorrido docente

1. **Mis documentos:** subir el material, abrir Detalles, procesar el texto y preparar el índice para buscar fuentes. Al estar listo aparece el enlace a Recursos.
2. **Recursos:** definir tema, objetivo y tipo. La personalización por perfil es opcional. Preparar recupera las fuentes y guarda la solicitud; todavía no genera con IA.
3. **Revisar las fuentes:** cotejar los fragmentos antes de pulsar Generar recurso. Revisar después el contenido y sus soluciones. Un recurso guardado se puede recuperar desde Mis recursos, sin generarlo otra vez.
4. **Asignar:** desde el recurso revisado, usar Asignar este recurso. El formulario conserva su identificador y muestra el título elegido; completar destinatario e instrucciones. También se puede asignar directamente un bloque fijo de ejercicios desde Actividades asignadas.
5. **Consultar actividades:** los bloques fijos muestran intentos y mejor resultado. Los recursos generados son materiales de consulta con soluciones: no registran respuestas, notas ni confirmación de lectura. Cerrar o cancelar conserva los resultados existentes; el material de consulta sigue disponible.

Buscar fuentes es una consulta opcional de los materiales. Perfiles de aprendizaje permite preparar apoyo opcional para la generación. Uso de generación muestra solicitudes, tokens y tiempos; el seguimiento estudiantil se consulta en Actividades asignadas.

No es necesario visitar la práctica libre del estudiante para completar este recorrido.
